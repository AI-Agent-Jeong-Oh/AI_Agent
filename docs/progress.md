# 현재까지 구현 기록

기록일: 2026-10-10

이 문서는 앞으로 할 일을 정하는 계획서가 아니라, 현재 저장소에 무엇을 어떤 방식으로 구현했고 어디까지 실제로 확인했는지를 설명하는 기록입니다.

## 전체 요약

Python과 PySide6를 사용해 macOS에서 실행되는 영상 중요 구간 선별 데스크톱 앱의 초기 기반을 만들었습니다. 사용자는 로컬 영상 파일을 선택하고, 분석 목적과 시간 범위를 입력하고, 표시된 분석 계획을 승인한 뒤 샘플 중요 구간을 확인할 수 있습니다. 후보를 선택하면 원본 영상의 해당 시작 시점으로 이동합니다.

현재 기본 결과는 영상 내용을 해석한 AI 결과가 아니라 길이를 기준으로 만든 샘플 결과입니다. 로컬 VLM과 외부 API를 연결할 수 있는 코드와 검증 구조는 구현했지만 실제 모델 호출은 수행하지 않았습니다.

## 구현한 사용자 흐름

다음 순서가 하나의 앱 안에서 이어지도록 구성했습니다.

```text
로컬 영상 선택
→ 영상 재생 및 메타데이터 확인
→ 분석 목적과 원본 시간 범위 입력
→ 필요한 경우에만 추가 질문
→ 분석 계획 표시
→ 사용자 승인
→ 백그라운드 분석
→ 중요 구간 후보 표시
→ 후보 클릭 시 원본 시점으로 이동
```

외부 API 모드에서는 분석 계획 승인만으로 실행되지 않습니다. 공급자, 목적지, 전송할 목적 텍스트와 JPEG 프레임 시각을 표시한 뒤 외부 전송을 별도로 승인하도록 분리했습니다.

## 영상 처리 구현 방식

- FFprobe로 영상 길이, 해상도, 평균·명목 FPS, 회전, codec, 오디오, 시작 시각과 timebase를 읽습니다.
- 앱 내부의 공통 시간은 원본 시작 기준 초 단위로 유지합니다. Qt 재생기와 연결되는 경계에서만 밀리초로 변환합니다.
- 가변 프레임률 영상의 시각을 프레임 번호를 FPS로 나누어 계산하지 않습니다.
- FFmpeg로 계획에 포함된 시각의 프레임만 제한적으로 추출합니다. 영상 전체를 메모리에 올리지 않습니다.
- 추출 결과에는 요청한 시각과 FFmpeg `showinfo`에서 확인한 실제 decoded PTS를 함께 기록합니다.
- 원본 영상은 수정하지 않으며 한글과 공백이 포함된 경로도 처리합니다.
- FFmpeg와 FFprobe는 shell을 통하지 않고 실행하며 취소나 시간 초과 시 하위 프로세스 그룹을 정리합니다.

## Agent와 승인 구현 방식

- 목적이 너무 짧거나 일반적일 때만 판단 기준을 묻는 추가 질문을 만듭니다.
- 분석 계획에는 영상, 목적, 모드, 모델, 시간 범위, 샘플 시각, 실행 시간과 프레임 한도가 포함됩니다.
- 계획 내용으로 fingerprint를 만들기 때문에 영상·목적·모델·범위·공급자 설정이 바뀌면 기존 승인이 무효화됩니다.
- 승인 전에는 분석 요청을 만들 수 없습니다.
- 기본 실행 한도는 계획당 1회이며 자동 재분석과 공급자 자동 재시도는 사용하지 않습니다.
- 분석 범위를 넓혀야 하는 경우 자동으로 실행하지 않고 제안 상태로만 남깁니다.
- 취소한 작업의 늦은 진행 이벤트나 결과가 현재 화면을 덮어쓰지 못하도록 작업 ID를 확인합니다.

## 분석기와 모델 연결 구조

분석기는 다음 세 종류를 구분합니다.

| 구분 | 현재 구현 |
|---|---|
| `sample` | 프레임을 해석하지 않고 승인 범위의 길이 비율로 후보 생성 |
| `local` | loopback 주소의 명시된 영상 입력 모델에 연결하는 어댑터 |
| `external` | HTTPS 외부 API에 별도 전송 승인 후 연결하는 어댑터 |

샘플 분석기와 실제 모델 분석기를 별도 클래스로 구성했습니다. 로컬 모델 연결에 실패해도 외부 API나 샘플 결과로 자동 전환하지 않습니다.

모델에는 승인된 시각에서 추출한 JPEG 프레임, 각 프레임의 원본 시각과 사용자 목적을 전달하도록 구성했습니다. 모델 응답은 다음 내용을 검사합니다.

- JSON 최상위 형식과 필수 필드
- 구간 시작과 종료 순서
- 승인된 분석 범위와 원본 영상 길이
- 실제 입력으로 전달한 frame ID인지 여부
- 요약, 관찰 근거와 불확실성 존재 여부
- 범죄 성립이나 사람의 의도를 확정하는 일부 위험 표현

잘못된 구간을 몰래 보정하거나 실패 결과를 샘플 결과로 바꾸지 않습니다. 테스트의 가짜 공급자 응답도 실제 모델 결과와 다른 `test_double` 출처로 표시합니다.

## 실행 안정성과 저장

- 메타데이터 확인과 분석을 Qt 백그라운드 작업으로 실행해 UI 이벤트 처리를 막지 않습니다.
- 중복 실행, 취소, 시간 초과, 손상 영상, 지원하지 않는 확장자와 잘못된 모델 응답을 오류 상태로 처리합니다.
- 실제 진행률을 알 수 없는 단계는 숫자를 추정하지 않고 불확정 진행 상태로 표시합니다.
- 설정과 결과는 `~/Library/Application Support/VideoAnalysisAgent`에 저장합니다.
- 추출 프레임 캐시는 `~/Library/Caches/VideoAnalysisAgent`에 저장합니다.
- 결과 JSON에는 원본 영상 경로를 넣지 않고 API 키 값도 저장하지 않습니다.
- 앱 소유 marker가 있는 캐시 폴더만 정리할 수 있도록 제한했습니다.

## PDF 연결 계약

PDF 추출이나 검색 자체는 구현하지 않았습니다. UI와 검색 코드가 나중에 같은 형식으로 연결될 수 있도록 검색 질의와 결과 계약을 만들었습니다. 결과에는 본문, 문서 ID, 문서명, 페이지, 자료 버전과 선택적인 검색 점수·임베딩 모델 정보를 담을 수 있습니다.

자료나 검색기가 없는 현재 상태에서는 가짜 출처를 만들지 않고 `PDF 지식 자료 없음/검색기 미연결`을 반환합니다.

## 개발용 패키징

PyInstaller 설정과 빌드 스크립트를 작성해 `dist/VideoAnalysisAgent.app`을 만들었습니다. 확인한 번들은 arm64, 약 113MB이며 bundle identifier는 `org.ai-agent-jeong-oh.video-analysis-agent.dev`입니다.

이 번들은 개발 확인용 ad-hoc 서명 상태입니다. 모델 가중치, 원본 영상, API 키와 Homebrew FFmpeg는 포함하지 않았습니다.

## 실제 검증 기록

- 자동 테스트 47개 통과
- Python `compileall` 통과
- `pip check` 결과 의존성 충돌 없음
- FFmpeg 8.1.2로 한글·공백 경로의 3초 H.264 합성 영상 생성
- FFprobe에서 길이 3.000초 확인
- Qt Multimedia에서 길이 3000ms와 재생 위치 208ms까지 진행 확인
- 샘플 후보 2개 생성과 첫 후보의 원본 300ms 위치 이동 확인
- 두 번째 실행 취소 후 늦은 결과가 목록과 저장 결과를 덮어쓰지 않음 확인
- PyInstaller 6.22.3으로 macOS arm64 `.app` 빌드 성공
- 번들 실행 파일을 offscreen으로 시작하고 종료 코드 0 확인

위 검증은 합성 영상과 오프스크린 UI를 사용했습니다. 실제 CCTV 분석 성능, 실제 로컬·외부 VLM 추론, 화면의 영상 출력과 오디오 청취, 인증서 서명·공증을 확인했다는 의미는 아닙니다.
